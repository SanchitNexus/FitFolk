# FitFolk Screenshots

This directory is designated for investor and showcase presentation screenshots.

### Recommended Capture List:
1. `01-home-feed.png` — Home feed in Dark Mode showing stories, post cards, and right sidebar.
2. `02-explore-page.png` — Explore and discovery page with category pills and search.
3. `03-profile-verified.png` — Profile of a verified trainer or dietitian showing credentials.
4. `04-workout-tracker.png` — Workout tracker dashboard with active session & rest timer.
5. `05-nutrition-tracker.png` — Nutrition tracker with daily calorie ring and macro progress.
6. `06-community-qa.png` — Community Q&A feed with verified professional answers.
7. `07-challenges.png` — Fitness challenge streaks and leaderboards.
8. `08-mobile-feed.png` — Mobile view showing compact header and bottom navigation.
9. `09-investor-tour.png` — The 6-step guided investor walkthrough modal.

### How to Capture Locally:
Run the development server:
```bash
npm run dev
```
Open `http://localhost:5173` in any modern desktop browser (Chrome, Edge, Firefox, or Safari), press `F12` to switch between desktop and mobile device emulation, and use the browser's "Capture full size screenshot" developer tool.
